# Reto del módulo 05

Este escenario cierra el laboratorio del módulo 05 de **Ruta Cloud Native**. Aquí no hay comandos para copiar: recibes los requisitos y los cumples con lo que practicaste en las dos partes anteriores.

El clúster empieza limpio, con dos nodos y el namespace `lab-05` ya creado. El namespace ya aplica el perfil `restricted` de Pod Security Admission (labels `enforce` y `warn`), así que cualquier Pod que crees tiene que cumplirlo.

Puedes pulsar **CHECK** las veces que quieras: te dice qué falta. La sesión dura como máximo una hora.

Espera a que la terminal muestre los dos nodos y pulsa **START**.
