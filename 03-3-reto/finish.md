# Reto superado

Has construido sin guía una aplicación con las piezas del módulo:

- un Deployment con una estrategia de actualización que nunca baja de 3 Pods disponibles,
- un ConfigMap montado como archivo, que cambia lo que sirve nginx sin tocar la imagen,
- un Secret inyectado como variable de entorno,
- un historial con dos revisiones, listo para un rollback.

Con esto termina el laboratorio del módulo 03 de **Ruta Cloud Native**. Vuelve al curso para hacer el examen del módulo.
